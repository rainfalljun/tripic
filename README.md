## 환경설정
1. VSC, Flutter SDK, Android Studio 설치
2. VSC -> Flutter, Dart 플러그인 설치
3. C: 디렉토리 밑에 디렉토리 생성 후 설치한 Flutter_SDK 압축파일 넣고 압축해제, 해제한 폴더 내 flutter/bin 폴더까지 들어가 경로 복사
4. 윈도우 검색창에서 시스템 환경 변수 편집 검색 고급 -> 환경 변수 -> 사용자 변수의 Path에 들어가서 새로 만들기 후 붙여넣기
5. Visual Studio 2022에서 C++를 사용한 데스크톱 개발 추가해서 설치
6. cmd -> 생성한 디렉토리 경로에서 입력 : flutter create .
7. Android Studio -> More Actions -> SDK Manager -> SDK Tools -> Android SDK Command-line Tools (latest) 클릭 후 Apply
8. cmd -> sdkmanager --licenses 입력 후 y 입력 해 라이선스 동의하기
9. cmd -> flutter doctor
10. [!] 떠있는 부분 수정
11. 플러터 폴더에서 우리는 앱을 제작하기 때문에 ios와 android 디렉토리를 남기고 삭제 (windows, macos, web, linux)
