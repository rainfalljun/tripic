## 환경설정
1. VSC, Flutter SDK, Android Studio 설치
2. VSC -> Flutter, Dart 플러그인 설치
3. C: 디렉토리 밑에 디렉토리 생성
4. cmd -> 생성한 디렉토리 경로에서 입력 : flutter create .
5. Android Studio -> More Actions -> SDK Manager -> SDK Tools -> Android SDK Command-line Tools (latest) 클릭 후 Apply
6. cmd -> sdkmanager --licenses 입력 후 y 입력 해 라이선스 동의하기
7. cmd -> flutter doctor
8. [!] 떠있는 부분 수정하기
9. 플러터 폴더에서 우리는 앱을 제작하기 때문에 ios와 android 디렉토리를 남기고 삭제 (windows, macos, web, linux)
